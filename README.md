# java-fundamentals-course-vantara

Código fuente del curso **Fundamentos de Java para Principiantes**, dirigido a estudiantes de secundaria (12 a 17 años) sin experiencia previa. A lo largo de 5 lecciones se construye un videojuego llamado **Pixel Quest** para aprender Java y programación orientada a objetos.

📘 **Plan del curso, lecciones en video y prácticas**: [course-plan.md](course-plan.md)

## Requisitos

Solo necesitas un navegador web. **No es necesario instalar nada.** Los ejemplos se ejecutan en un editor Java en línea, como [OnlineGDB](https://www.onlinegdb.com/online_java_compiler) o [JDoodle](https://www.jdoodle.com/online-java-compiler).

## Cómo usar este repositorio

1. Mira la lección en video desde el [plan del curso](course-plan.md).
2. Abre un editor Java en línea.
3. Copia el código de `starter-files/` (punto de partida) y complétalo mientras sigues la lección.
4. Compara tu resultado con `completed-examples/`.
5. Presiona **Run** para ejecutar el programa.

> Si el editor te pide un nombre de archivo, usa `Main.java`: la clase principal de los ejemplos se llama `Main`.

## Estructura del repositorio

| Carpeta | Contenido |
|---|---|
| `starter-files/` | Archivos guiados para comenzar cada práctica, con los pasos comentados. |
| `completed-examples/` | Programas terminados, listos para ejecutar. |
| `scripts/` | Versiones comentadas línea por línea para estudiar el código. |

### Archivos por lección

| Lección | Tema | Archivos |
|---|---|---|
| 1 | Introducción a Java | `PixelQuest.java` |
| 2 | Variables y decisiones | `Variables.java` |
| 3 | Métodos | `Metodos.java` |
| 4 | Clases y objetos | `Personaje.java` |
| 5 | Arrays e integración de conceptos | `Arreglos.java`, `Aventura.java` (solo en `completed-examples/`) |
