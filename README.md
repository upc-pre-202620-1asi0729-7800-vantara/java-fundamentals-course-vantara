# Fundamentos de Java para Principiantes

## Resumen del Curso

Este curso de media hora introduce a estudiantes de secundaria a los fundamentos de la programación con Java, incluyendo programación orientada a objetos. **¡No requiere descargas!** Solo se necesita de tu navegador web favorito.

**Duración total**: ~30 minutos
**Público Objetivo**: Estudiantes de 12 a 17 años sin experiencia en programación
**Prerrequisitos**: Ninguno
**Herramientas necesarias**: **¡Solo tu navegador web!** (Chrome, Firefox, Safari, Edge, Brave, Opera, etc.)
**📂 Repositorio de Código Fuente**: [https://github.com/upc-pre-202620-1asi0729-7800-vantara/java-fundamentals-course-vantara](https://github.com/upc-pre-202620-1asi0729-7800-vantara/java-fundamentals-course-vantara)

## Secuencia de la Lección

### Lección 1: ¡Bienvenido al mundo de la programación! (4 minutos)
- **Descripción**: Comprende qué es programar, qué es un algoritmo, qué es un lenguaje de programación, por qué utilizaremos Java y cómo ejecutar el primer programa.
- **Enlace**: [Ver la lección](https://youtu.be/snxYz-xj7bg?si=qhYJ_KsRbgmkJKOC)
- **Conclusiones clave**: Java se usa para aplicaciones, videojuegos y apps Android; los programas son instrucciones para computadoras.
- **Empieza a programar**: [Abrir JDoodle - ¡Bienvenido a Pixel Quest!](https://onlinegdb.com/B-yEb6s5j) 👈 **¡No requiere instalación, es totalmente gratuito!**

### Lección 2: ¡Dale vida a tu videojuego! Variables y decisiones (5 minutos)
- **Descripción**: Aprende variables, tipos de datos, operadores, expresiones, entrada y salida, condicionales y bucles.
- **Enlace**: [Ver la lección]()
- **Conclusiones clave**: Usa int, String, double, boolean; declara como `String nombre = "David";`,`String apellido = "Apellido";`; opera con +, -, *, /, %.
- **Práctica**: [Clic para programar](https://www.jdoodle.com/ia/x6f3-dax9-7tu3) 👈 **¡No es necesario registrarse!**

### Lección 3: ¡Enseñale nuevos movimientos a tu personaje! Métodos (6 minutos)
- **Descripción**: Comprender que son los métodos, por qué se utilizan, cómo se crean, qué son los parámetros y argumentos, y cómo devolver resultados.
- **Enlace**: [Ver la lección]()
- **Conclusiones clave**: `public static int calcularVida(int vidaActual, int danio) {}`
- **Práctica**: [Clic para programar](https://onlinegdb.com/DGi75Xgtp) 👈 **¡Inicio inmediato!**

### Lección 4: ¡Construye tus propios personajes! Clases y Objetos (6 minutos)
- **Descripción**: Comprender qué es la POO, las clases, los objetos, los atributos, comportamientos, constructores, instaciación y encapsulamiento mediante getters y setters.
- **Enlace**: [Ver la lección Métodos](https://www.youtube.com/watch?v=VLcEStoogvA)
- **Conclusiones clave**: `Personaje caballero = new Personaje();`; `caballero.nombre = "Thor";`, `Personaje mago = new Personaje();`.
- **Práctica**: [Haz clic para practicar](https://onlinegdb.com/ScGsddFovv) 👈 **¡No necesitas registrarte!**

### Lección 5: ¡Tu primera aventura en Java! Construyendo un videojuego (8 minutos)
- **Descripción**: Integrar clases, objetos constructores, métodos, encapsulamiento, arrays y cadenas de texto en un programa funcional. Además, aprender buenas prácticas de programación y errores frecuentes.
- **Enlace**: [Ver la lección](https://youtu.be/nnnImupxJAQ)
- **Conclusiones clave**: Clase = molde; objeto = instancia; `private` protege datos; getters/setters los exponen; arrays de objetos como `String[] mochila = new String[3];;`
- **Proyecto final**: [Visualiza lo aprendido de POO](https://onlinegdb.com/mYcwPH3NC) 👈 **¡Guarda y comparte!**
